# 챕터 간지

## 필수 적용

- 목차의 큰 주제(대분류)마다 본문 앞에 간지를 반드시 추가합니다. 첫 챕터에도 적용합니다.
- 사용자가 이미 만든 간지가 있으면 그대로 활용하며 중복으로 만들지 않습니다.
- 간지는 목차와 같은 챕터 번호·이름으로 해당 묶음의 시작을 알려야 합니다. 목차에 없는 대분류나 내용을 임의로 만들지 않습니다.
- 모든 하위 항목에 간지를 반복하지 않습니다. 하위 주제의 새 행 구분과 큰 목차의 간지를 구별합니다.
- 추가된 간지도 전체 장수와 페이지 산정에 포함합니다. 고정 장수와 충돌하면 간지를 몰래 생략하지 않고 필요한 조정을 확인합니다.

## 디자인과 배치

- 사용자가 편집한 간지의 문구·도형·스타일을 유지합니다. 기존 간지가 없는 경우 이번 발표의 확정된 디자인 규칙과 선택한 간지 레퍼런스를 적용합니다.
- 02-common-layout의 간지 예외를 따르며, 간지에는 페이지 번호를 표시하지 않습니다. 나머지 화면 크기·폰트·여백 등 공통 규칙은 유지합니다.
- 간지도 [공통 헤더 로고](../02-common-layout/components.md#헤더-로고)를 포함합니다. 본문의 헤더를 재사용하며, 이번 발표에서 지정한 로고와 배치를 따릅니다.
- 캔버스의 챕터별 행·열 배치는 [캔버스 장표 배치](../10-production-rules/canvas-layout.md)를 따릅니다. 새 행 첫 열의 간지와 오른쪽으로 이어지는 본문처럼 사용자가 정한 시작 경계를 유지합니다.
