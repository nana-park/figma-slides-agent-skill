# 목차 레이아웃

## 1. 목차-1

### 적용 조건과 기준 샘플

- 발표의 대분류와 하위 항목, 짧은 설명, 페이지 범위를 함께 보여주는 목차에 사용합니다.
- 기준 프레임: 목차-1 (사용자 제공 레퍼런스 필요)
- 파일: 사용자 지정 레퍼런스 / 페이지: 목차
- 화면은 1920×1080px이며 폰트는 모든 요소에 Pretendard Variable을 사용합니다.
- 프레임 내부에 보이는 요소만 기준으로 삼습니다. 프레임 밖의 옛 텍스트·구분선은 사용하지 않습니다.

### 공통 규칙과의 관계

목차는 일반 장표의 챕터명·제목·부제목·본문 고정 좌표와 1~3열 본문 그리드를 사용하지 않고 아래 배치를 적용합니다. 목차의 제목은 결론형 문장 대신 Index 같은 식별명을 사용할 수 있습니다. 글자 크기·행간은 아래 목차 전용 값을 적용하고, 색상과 배경은 01-design-system을 따릅니다.

아래 좌표는 샘플 실측값입니다. 목차 콘텐츠의 좌우 여백은 약 50px로, 일반 장표의 80px 여백에 대한 예외입니다. 헤더·저작권·출처는 별도 예외를 지정하지 않았으므로 공통 규칙을 유지하되 Index와 겹치지 않도록 확인합니다. 목차 자체의 페이지 번호는 표시하지 않지만 전체 페이지 산정에는 포함합니다.

### 배치와 간격

좌표는 프레임 좌측 상단 기준, 단위는 px입니다. 현재 샘플은 6개 행으로 구성되어 있습니다.

| 요소 | 기준 위치 | 배치 기준 |
|---|---|---|
| 목차 식별명 Index | X=51, Y=50 | 좌측 정렬 |
| 대분류명 | X=44, Y=240 / 581 / 815 | 각 그룹의 첫 행에 한 번 표시 |
| 항목 번호 | X=642 | 각 행의 시작 Y와 동일 |
| 항목 제목 | X=753 | 좌측 정렬 |
| 짧은 설명 | X=1144, W=472 | 좌측 정렬, 한 줄 |
| 페이지 범위 | 오른쪽 끝 X=1845 | 우측 정렬, 내용 길이에 따라 왼쪽 시작점 변경 |
| 행 구분선 | X=51, W=1818 | Y=312 / 425 / 540 / 655 / 768 |

- 행 시작 Y: 235 / 349 / 462 / 576 / 692 / 805.
- 행 시작점 사이 거리는 약 114px입니다. 텍스트 행간 45px와 구분합니다.
- 그룹 구성은 샘플에서 3행 / 2행 / 1행입니다. 실제 목차의 분류에 맞춰 그룹을 바꾸고 대분류명은 해당 첫 행에 맞춥니다.
- 샘플은 자동 레이아웃이 없는 절대 배치입니다. 위 간격은 요소 간 거리이며 박스 내부 패딩을 뜻하지 않습니다.
- 항목이 늘면 글자를 줄이거나 하단 공통 영역을 침범하지 않고 목차를 다음 장으로 나눕니다.
- 설명이나 제목이 열 너비를 넘으면 문구를 간결하게 다듬습니다. 다음 열과 겹치지 않도록 확인합니다.

### 타이포그래피

크기와 행간은 샘플을 기준으로 하며, 다른 폰트가 쓰인 요소도 Pretendard Variable로 교체합니다. Index의 원본 행간은 AUTO이므로 제작 시 박스 높이 26px를 기준으로 26px로 명시합니다. 대분류의 원본 행간 약 34.63px는 35px로 정리합니다.

| 역할 | 폰트 | 굵기 | 크기 | 행간 | 색상 |
|---|---|---|---|---|---|
| Index | Pretendard Variable | Bold 700 | 22px | 26px | Grey 900 |
| 대분류명 | Pretendard Variable | Bold 700 | 25px | 35px | Grey 900 |
| 항목 번호 | Pretendard Variable | Regular 400 | 25px | 45px | Grey 600 |
| 항목 제목 | Pretendard Variable | Medium 500 | 25px | 45px | Grey 900 |
| 짧은 설명 | Pretendard Variable | Light 300 | 26px | 45px | Grey 600 |
| 페이지 범위 | Pretendard Variable | Light 300 | 25px | 45px | Grey 600 |

폰트 교체 후 글자 폭이 달라질 수 있으므로 열 사이 겹침과 잘림을 확인합니다. 구분선은 샘플의 가는 중립색 선을 유지합니다.

### 내용 교체

- 대분류명: 실제 발표의 챕터명으로 교체합니다.
- 항목 번호: 실제 대분류·항목 순서에 맞춰 1.1, 1.2 등의 형식으로 표시합니다.
- 항목 제목: 해당 프로젝트 또는 장표 묶음의 제목을 사용합니다.
- 설명: 해당 항목의 핵심 내용을 한 줄로 요약합니다.
- 페이지 범위: 실제 덱의 시작·끝 페이지로 계산합니다. 샘플 숫자를 복사하지 않습니다. 텍스트의 dash 금지 규칙에 따라 4~13처럼 표시합니다.
- 설명글·프로젝트 1 등 샘플 문구는 완성본에 남기지 않습니다.
