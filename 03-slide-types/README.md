# 장표 유형

내용에 맞는 구성 패턴을 정합니다. 목차의 큰 주제를 여는 챕터 간지는 필수이며, 나머지 모든 유형을 반드시 사용할 필요는 없습니다.

## 유형별 상세 규칙

- [표지 레이아웃 · AI 채용 과제·제안서 / 자기소개·포트폴리오](cover.md): 앞표지·뒤표지 샘플과 브랜드·문구 교체 규칙을 적용합니다.

- [목차 레이아웃 · 목차-1](contents.md): 대분류·항목 번호·제목·설명·페이지 범위를 행으로 배치합니다.
- [챕터 간지](chapter-divider.md): 목차의 큰 주제가 시작될 때마다 본문 앞에 반드시 배치하며, 기존 사용자 간지는 재사용합니다.
- 해당 유형을 사용할 때 상세 MD의 실제 규칙을 최종 프롬프트의 [장표 유형]에 함께 넣습니다.

## 본문-1 · 배경 분리형

기준: 사용자 지정 레퍼런스 · 본문 · 본문-1 (사용자 제공 레퍼런스 필요). 기존 샘플 03 · 내용에 해당합니다.

- 제목 영역과 카드 등 본문 묶음을 배경으로 구분하는 유형을 선택했을 때만 적용합니다. 모든 일반 장표에 배경 분리를 적용하지 않습니다.
- 배경 경계 Y = 첫 번째 본문 요소의 상단 Y − 50px입니다. 카드형 본문에서는 카드 바깥 박스의 상단을 기준으로 하며 카드 안 텍스트를 기준으로 삼지 않습니다.
- 상단 배경은 X=0, Y=0, W=1920, H=배경 경계 Y, 색상 #FFFFFF입니다.
- 하단 배경은 X=0, Y=배경 경계 Y, W=1920, H=1080 − 배경 경계 Y, 색상 #F2F5FA입니다.
- 공통 마스터의 본문 시작점 Y=360일 때 경계는 Y=310입니다. 310px를 모든 장표의 고정 경계값으로 사용하지 않습니다. 본문 시작점이 이동하면 경계도 함께 이동합니다.
- 기본 본문 시작점은 공통 마스터를 따릅니다. 제목·부제목과 배경 경계가 겹치면 이 유형에 한해 본문 시작점을 아래로 옮겨 여백을 확보한 뒤 경계를 다시 계산합니다. 헤더와 푸터는 이동하지 않고 본문 하단 한계 Y=944를 유지합니다.
- 본문 시작점을 내린 만큼 사용 가능한 본문 높이를 줄입니다. 내용이 넘치면 장표를 분리하며 글자를 임의로 축소하지 않습니다.
- 나머지 타이포그래피·그리드·카드 스타일은 01-design-system 및 02-common-layout 규칙을 적용합니다.
- 이 유형을 사용할 때 위 규칙을 최종 프롬프트의 [장표 유형]에 포함합니다.

## 입력 양식

| 유형 | 사용 목적 | 원하는 구성 |
|---|---|---|
| 표지 | 주제 소개 | [목적별 앞·뒤 표지](cover.md) |
| 목차 | 전체 구성 안내 | [목차-1](contents.md) |
| 핵심 요약 | 결론 정리 | [입력] |
| 섹션 표지 | 큰 주제 전환 | [챕터 간지 · 필수](chapter-divider.md) |
| 문제 정의 | 문제와 근거 설명 | [입력] |
| 비교 | 대안/전후 비교 | [입력] |
| 프로세스 | 단계 설명 | [입력] |
| 데이터 | 수치와 해석 전달 | [입력] |
| 일정 | 계획과 마일스톤 전달 | [입력] |
| 마무리 | 결정/행동 요청 | [입력] |

## 입력 안내

- 필수: 유형 결정 방식 (직접 지정/AI 추천).
- 조건부: 사용할 장표 유형과 구성 (직접 지정 시).
- 선택: 사용하지 않을 유형.
- 선택: 유형별 반복·변형 허용 범위.

이미 기록된 값은 다시 묻지 않습니다. 필요한 값이 없으면 질문하고 이 문서에 반영합니다. 선택 항목은 비워도 되며, 작성 예시는 확정값이 아닙니다.
