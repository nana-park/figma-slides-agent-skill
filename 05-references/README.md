# 디자인 레퍼런스

자료마다 무엇을 참고할지 지정합니다. 링크만 남기지 말고 이미지, 페이지 또는 Figma 노드 등 참고 위치를 적습니다.

## 입력 양식

### 레퍼런스 A
- 이미지 파일 또는 URL: [입력]
- 참고 페이지/프레임/노드: [입력]
- 참고할 요소: [컬러 / 폰트 / 여백 / 배치 / 그래프 / 기타]
- 구체적으로 참고할 점: [입력]
- 가져오지 않을 요소: [입력]
- 적용할 장표: [전체 또는 장표 번호]

### 레퍼런스 B
- 이미지 파일 또는 URL: [입력]
- 참고 페이지/프레임/노드: [입력]
- 참고할 요소: [입력]
- 구체적으로 참고할 점: [입력]
- 가져오지 않을 요소: [입력]
- 적용할 장표: [입력]

## 작성 예시

A는 컬러만, B는 여백과 배치만, C는 그래프 라벨 표현만 참고.

## 사용 규칙

- 레퍼런스의 문구와 수치를 실제 발표 내용으로 가져오지 않습니다.
- 열 수 없는 자료는 확인된 것으로 취급하지 않습니다.
- 이미지 파일은 이 폴더에 추가하고 파일명을 입력할 수 있습니다.

[전체 작성 안내로 돌아가기](../README.md)

## 입력 안내

- 필수: 레퍼런스 사용 여부 (없음 가능).
- 조건부: 자료 경로/URL와 참고 위치 (사용 시, 자료마다).
- 조건부: 참고할 요소·적용 장표·참고 강도 (사용 시. 분위기만/배치 유지 등).
- 선택: 제외할 요소.
- 선택: 자료 확인 상태 (내용 미확인은 조립 자체를 막지 않음).

이미 기록된 값은 다시 묻지 않습니다. 필요한 값이 없으면 질문하고 이 문서에 반영합니다. 선택 항목은 비워도 되며, 작성 예시는 확정값이 아닙니다.

## 교육용으로 검증한 구성 참고

- [교육 스토리 흐름](../references/teaching-story-flow.md): 학습 목표에 따른 장표 간 질문·활동·회고 연결. 교육 강의의 구성안을 설계할 때 읽습니다.
- [교육 장표 수정 사례](../references/course-revision-patterns.md): 후보×기준 비교표, 개념 비교와 통합 결론, 전체 프레임워크 활동, 기업 근거, 실제 게임 상태별 안내. 해당 유형을 만들 때 읽습니다.
- 공개본에는 내부 Figma 파일이나 노드 링크가 없습니다. 현재 사용자가 제공한 레퍼런스를 확인합니다.
- 다른 강의의 문구·브랜드·학생 정보·게임 규칙을 복사하지 않고 최신 사용자 편집을 보존합니다.
