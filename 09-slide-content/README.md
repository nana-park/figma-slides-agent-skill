## 입력 안내

- 필수: 내용 준비 방식 (직접 입력/원본 자료 기반/AI 구성 제안).
- 필수: 반드시 전달할 내용 또는 원본 자료 연결 (사실을 임의 생성하지 않음).
- 조건부: 각 실제 장표의 제목·핵심 메시지·본문 근거 (직접 입력 시, 모든 실제 장표에 반복).
- 조건부: 수치·단위·기간·출처 (수치/외부 사실 사용 시).
- 조건부: 내용 위임 범위와 구성안 확정 방식 (AI 구성 제안 시).
- 선택: 장표별 시각화·레퍼런스·예외.
- 선택: 발표자 노트.

이미 기록된 값은 다시 묻지 않습니다. 필요한 값이 없으면 질문하고 이 문서에 반영합니다. 선택 항목은 비워도 되며, 작성 예시는 확정값이 아닙니다.
