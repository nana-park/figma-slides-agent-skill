# 원본 자료와 조사 기준

아래 입력 양식에 필요한 내용을 작성합니다. 이미 확정된 값은 유지하고 빈칸만 확인합니다.

## 입력 양식

- 사용할 원본 자료 유무: [입력]
- 파일/URL·사용할 페이지/시트·용도: [입력]
- 외부 조사 허용 범위: [입력]
- 기준 시점·최신성·허용 출처: [입력]
- 자료 간 우선순위·계산 기준: [입력]
- 원문 유지·요약·인용 범위: [입력]

## 작성 원칙

자료마다 파일/URL, 사용할 페이지·시트, 용도, 기준 시점을 기록합니다. 외부 조사 허용은 특정 정보 조사 범위이며 파일 공유나 업로드 권한을 뜻하지 않습니다.

[전체 안내](../README.md)

## 입력 안내

- 필수: 사용할 원본 자료 유무 (없음 가능).
- 조건부: 파일/URL·사용할 페이지/시트·용도 (자료 사용 시, 자료마다).
- 필수: 외부 조사 허용 범위 (금지/특정 출처만/허용).
- 조건부: 기준 시점·최신성·허용 출처 (외부 조사 허용 시).
- 조건부: 자료 간 우선순위·계산 기준 (여러 원본이 충돌하거나 연산 필요 시).
- 선택: 원문 유지·요약·인용 범위.

이미 기록된 값은 다시 묻지 않습니다. 필요한 값이 없으면 질문하고 이 문서에 반영합니다. 선택 항목은 비워도 되며, 작성 예시는 확정값이 아닙니다.

## 기업 사례의 주장과 근거

- 고객에게 약속하는 가치와 그 약속을 믿을 구체적 이유를 구분합니다. '빠르고 간편하다'를 가치와 근거 칸에 반복하지 말고, 어떤 절차·성능·실제 경험·검증 결과가 그 가치를 뒷받침하는지 연결합니다.
- 출시 시점은 배경 정보일 수 있으나 그것만으로 성능이나 신뢰의 증거가 되지 않습니다. 정부 행사 참석·협약 보도를 정부 인증이나 사용자 반응으로 과장하지 않습니다.
- 사건 발생일, 당시 보도일, 나중에 제작된 회고 콘텐츠의 공개일을 구분합니다. 당시 고객에게 인상적이었다는 해석에는 별도의 반응 근거가 필요합니다.
- 기업의 실제 공식 전략·발언과 수업용 재구성을 구분합니다. 외부 기업이 내부적으로 이 비교표를 사용했다고 근거 없이 쓰지 않습니다. 가설·분석임은 필요한 곳에서 간결하게 구분하고, 모든 카드에 긴 면책 문구를 반복하지 않습니다.
- 특정 슬로건이 그대로 보이는 공식 이미지를 요청받으면 그 문구가 실제 보이는 공식 이미지 또는 공식 홈페이지 캡처를 찾습니다. 다른 공식 이미지, 재작성한 광고, 비슷한 문구의 히어로로 대체하지 않습니다.
- 프레임워크의 원래 기준과 강사가 만든 질문·등급을 분리합니다. 예를 들어 pain의 강도·빈도를 설명하는 원자료를 공식 '높음/중간/낮음' 판정표나 곱셈 공식의 출처로 사용하지 않습니다.

- 사례의 숫자는 비용·매출·투자·신청·실사용 중 무엇인지 적습니다. 서로 다른 단계에서 나온 광고비와 신청자 수를 하나의 획득 성과로 결합하지 않습니다.
- 시장 진입 사례는 당시 상황 → 확인된 행동 → 관측된 반응 → 학습상 의미를 연결합니다. 실제 송금 베타, 중단, 클로즈베타, 정식 출시처럼 상태를 구분하고, 도식의 편의를 위해 없는 제품 단계를 만들지 않습니다.
- 서로 다른 사건의 날짜 정밀도가 다르면 연도만 아는 사건에 임의 월·선후 관계를 붙이지 않습니다. 투자가 은행 제휴를 만들었다거나 손편지가 금융망 계약을 성사시켰다는 인과는 별도 근거가 있어야 합니다.
- 실제 회사 로고·화면 옆에 가상의 수강생 적용 상황을 붙이면 실제 역사로 오인될 수 있습니다. 적용 활동임을 분리해 표시하고, 모호한 혼합 장표를 늘리지 않습니다.

- 외부 개념·주장에는 확인된 원저자·원자료를 표시합니다. 강사가 자료를 재구성했다는 이유만으로 강사 이름을 그 개념의 출처로 대체하지 않습니다. 강사가 만든 활동에 불필요한 자기 인용을 붙이지 않습니다.
- 앱 내부 사용 경로, 실제 유입 경로, 첫 시장 진입, 현재 수익화, 재출시는 서로 다른 사건입니다. 공식 사이트·앱스토어 화면만으로 실제 주요 유입 채널을 입증하지 않으며, 하나의 캠페인을 브랜드 전체의 주 채널로 일반화하지 않습니다.
