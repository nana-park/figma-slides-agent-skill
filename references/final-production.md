# 최종 제작 검수

실제 고객 경로와 화면 내부 경로, 첫 시장 진입과 현재 수익화는 구분한다. 공식 화면만으로 주요 유입 채널을 입증하지 않는다.

공식 이미지·로고는 사용 조건을 확인한다. 요청한 문구나 장면이 실제로 보이는지 확인하고 비슷한 이미지로 근거를 대체하지 않는다. 로고와 주장을 보여주는 시각 자료는 별도 역할이다.

기존 카드를 재사용하면 편집 가능한 구조·스타일·패딩·색상 연결을 읽고 대응 요소만 교체한다. 보이지 않는 SVG, 마스크 누락, 잘못된 크롭은 실제 렌더링에서 확인한다.

최종 활성 장표의 읽기 순서, 레이어 순서, 표시 이름, 푸터 숫자와 목차 범위를 전수 대조한다. 무번호 예외·숨김·사용자 추가 장표를 포함한 검사 범위를 기록한다.

원본 확보, 사용자 전달, 장표 삽입, 화면 확인은 서로 다른 상태다. 삽입이 막히면 원인과 미완료 범위를 명시한다. 승인된 수동 작업이 필요하면 대상과 위치를 정확히 전달한다.
