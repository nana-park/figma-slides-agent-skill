# 교육 장표 구성 패턴

## 비교

후보를 열, 평가 기준을 행으로 두고 모든 교차 셀을 같은 기준으로 설명한다. 후보와 기준, 평가 결과, 최종 선택의 위계를 구분한다. 자료가 없으면 미확인으로 둔다.

관련 개념은 정의·판단 질문·적용 예시를 대응시킨다. 개념 간 차이와 함께 사용하는 통합 결론은 시각적으로 구분한다.

## 활동

학습한 프레임워크의 필수 항목을 활동 양식에 대응시킨다. 학습 전 진단 초안과 학습 후 적용 결과를 구분한다. 실제 학생 기록은 예시로 배포하지 않는다.

## 기업 근거

가치 주장과 그 주장을 뒷받침하는 행동·성능·검증 결과를 연결한다. 출시일, 행사 참석, 협약만으로 신뢰·효과·인증을 단정하지 않는다. 기업의 공식 전략과 강의용 해석을 분리한다.

## 화면 안내

실제 도구의 현재 상태와 버튼명을 확인하고 복잡한 안내는 화면 또는 상태별로 나눈다. 제출 후 대기와 결과 화면을 구분한다. 다른 도구의 규칙을 섞지 않는다.

## 사용자 수정 보존

사용자가 완성한 기준 카드를 대응되는 형제 카드에 적용할 때 기준 카드의 문구·줄바꿈·삭제 상태를 보존한다. 숨긴 과거 안을 복원하지 않는다.

## 구조 검사

제목의 외관뿐 아니라 부모 Auto Layout, 자식 순서, 일반 흐름·absolute 배치, FIXED/HUG/FILL, 텍스트 자동 높이를 검사한다. 고정 높이만으로 구조 오류를 판정하지 않는다. 구조 전수 검사와 대표 화면 확인 범위를 따로 보고한다.
