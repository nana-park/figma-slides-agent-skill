# 교육 스토리 흐름

각 장표는 앞 장의 질문을 받고 다음 판단을 연다. 도입 질문·대조·정의·근거·체험·회고·팀 적용 중 학습목표에 필요한 기능을 선택한다.

- 개념의 필요성을 느끼는 문제나 대조를 먼저 제시할 수 있다.
- 연구는 고민 → 비교 조건과 방법 → 결과 → 적용 의미와 한계로 연결한다.
- 체험은 재미에서 끝내지 않고 관찰한 차이와 다음 설계 판단으로 돌아온다.
- 개념을 적용할 때 작성 과정 또는 합성 완성 예시를 보여준다.
- 진단용 초안은 학습 후 다시 검토하도록 보존한다.
- 같은 사례를 재사용하면 관점 차이를 명확히 하고, 실제 기업 사실과 가상 적용을 구분한다.
- 후속 수업의 내용을 현재 단원에 모두 넣지 않고 연결 질문만 남긴다.
- 설명·개인 생각·팀 의논·발표·회고 시간을 따로 산정한다. 무관한 장표로 시간을 채우지 않는다.
- 발표자가 화면을 중심으로 설명한다면 이해에 필요한 조건과 맥락을 화면에 남기고 과밀할 때 여러 장으로 나눈다.
- 사용자 삭제·숨김·최신 수정과 승인된 학습목표를 우선한다.

합성 흐름 예시: 가상 서비스의 선택 문제 → 판단 기준 소개 → 같은 조건의 비교 → 짧은 적용 활동 → 근거·한계 회고 → 다음 검증 계획. 실제 수강생 정보나 특정 강의 기록을 뜻하지 않는다.
