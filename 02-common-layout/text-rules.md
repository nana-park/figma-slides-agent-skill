# 텍스트 내용 규칙
- 한 장에 핵심 메시지는 하나만 전달한다. 본문은 그 메시지를 설명하거나 입증하는 내용으로만 구성한다.
- 제목은 해당 장의 핵심 결론을 담은 완결된 한 문장으로 쓴다. 주제명이나 명사 나열만으로 작성하지 않는다. 국문은 '-습니다'체로 완결합니다.
   - 예: 사용성 분석 대신 복잡한 가입 절차가 첫 사용 전 이탈을 높인다.처럼 쓴다. 실제 근거가 있는 범위에서만 결론을 단정한다.
- 일반 마스터 제목은 지정된 한 줄 영역에 맞춘다. 최신 사용자 지시·직접 편집한 원본 또는 명시적으로 선택한 전용 유형에 두 줄 예외가 있을 때만 해당 장표에 적용한다. 글자 수만으로 자동 줄바꿈하지 않는다.
- 두 줄 예외에서는 단어·의미 단위로 끊어 가독성을 지키고 실제 제목 영역 높이와 본문 비겹침을 검사한다. 예: 복잡한 가입 절차가 / 첫 사용 전 이탈을 높입니다. 이 예시는 일반 장표를 두 줄로 바꾸라는 지시가 아니다.
- 길다고 글자를 줄이거나 본문·푸터를 밀지 않는다. 새 문구는 지정 영역에 맞게 다듬되, 구조 수정 시 사용자가 완성한 문구·줄바꿈·삭제는 보존한다. 허용 범위 안에서 해결할 수 없는 넘침은 확인할 항목으로 남긴다.
- 제목에서 강조해야 하는 핵심 단어 또는 짧은 구절은 Blue 500 (#3182F6)으로 표시한다.
- 부제목은 결론의 조건·범위·대상 등 보조 맥락을 한 줄로 제시한다. 제목을 반복하지 않는다.
- 챕터명은 문서 내 분류를 짧게 표시한다. 본문은 핵심 근거부터 배치한다.
- 정보의 출처가 있다면 꼭 표기한다. 장표 하단은 공통 레이아웃의 `저자(연도)` 형식만 사용하고 URL 및 클릭 하이퍼링크는 제거한다. 상세 서지정보·원문 링크는 발표자 노트나 별도 원고에 보존한다.
   - 출처가 불명확한 수치·인용을 만들어 넣지 않는다. 사실, 사용자 제공 정보, 작성자의 해석을 구분한다.
- 내용이 많으면 글자를 줄이기보다 장표를 분리한다.
- 내용이 많으면 글자 크기를 줄이지 말고 장표를 분리한다. 분리된 장표도 각각 하나의 결론형 제목을 가진다.

## 카드 안의 강조 규칙

- 카드 제목도 핵심 단어 또는 짧은 구절에 Blue 500 (#3182F6)을 적용한다. 제목 전체를 강조색으로 바꾸지 않는다.
- 카드 본문은 핵심 단어 또는 최대한 짧은 구절만 Bold 700으로 강조한다. 문장 전체를 굵게 만들지 않는다.
- 본문의 강조 여부와 관계없이 글자 크기·행간·기본 색상은 동일하게 유지한다.
- 카드 위쪽 단계 번호는 버튼 형태로 표시하고, 하단 보조 설명은 일반 텍스트로 유지한다.

## 강의 전달과 용어 병기

- 영문 용어와 대응하는 한글 표현 사이에는 가운데점 '·' 대신 한 칸 띄어쓰기를 사용합니다. 예: 'Segmentation 세분화', 'Customer jobs 고객의 할 일'. 서로 다른 항목을 구분하는 가운데점까지 금지하는 규칙은 아닙니다.
- 이 강의는 강사가 화면을 보며 설명하는 방식입니다. 필요한 맥락을 발표자 대본으로 모두 옮겨 화면을 빈약하게 만들지 않습니다. 한 장에 많으면 핵심 설명이 화면에서 읽히도록 2–3장으로 나눕니다. 상세 서지정보를 별도 기록하는 출처 규칙과는 구분합니다.
- 약어와 새 개념은 첫 사용 시 풀네임과 쉬운 뜻을 먼저 제공합니다. 빈 양식이나 프레임워크 이름만 제시하고 학생이 이미 안다고 가정하지 않습니다.
