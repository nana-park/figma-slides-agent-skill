# 전체 레이아웃
모든 페이지는 `1. 공통 레이아웃`을 기본으로 적용합니다. `2. 예외 페이지`는 해당 페이지 유형에서 달라지는 항목만 정의하며, 공통 규칙과 충돌할 때는 명시된 예외 항목을 우선합니다. 예외에 적지 않은 항목은 공통 규칙을 그대로 따릅니다. 예를 들어 표지는 제목·본문의 고정 좌표와 페이지 번호에 예외를 적용하지만, 캔버스 크기·안전 여백·폰트 및 그 밖의 공통 규칙은 유지합니다.

## 1. 공통 레이아웃
- 사용자 지정 좌표와 아래의 고정 마스터가 추가로 입력한 디자인 및 컴포넌트 예시보다 우선합니다.
- 아래 크기와 간격은 공통 기본값입니다. 페이지별 임의 변경은 금지합니다.

### 1) 레이아웃 안정성과 밀도
- 콘텐츠는 화면 중심부에 응집된 시각적 덩어리로 구성합니다. 중앙 배치는 텍스트 가운데 정렬을 의미하지 않습니다.
- 주요 도표·이미지·텍스트가 본문 영역을 충분히 사용하도록 크기를 조절합니다. 작은 요소를 모서리에 흩어 놓거나 내용을 화면 끝까지 벌려 배치하지 않습니다.
- 내용이 적으면 핵심 도표나 이미지를 확대하거나 의미상 연관된 내용을 묶습니다. 불필요한 문장·장식으로 채우지 않습니다.
- 정해진 프레임·그리드·간격을 사용하고, 콘텐츠 길이에 따라 제목이나 푸터가 밀리지 않도록 각 영역을 분리합니다.
- 간격은 역할별로 적용합니다. 상단 챕터·제목·부제목 사이는 5px, 카드 내부 주요 묶음 사이는 20px, 카드 사이는 60px입니다. 제목 묶음과 본문 사이의 거리는 아래 좌표를 따릅니다.
- 텍스트 넘침, 잘림, 겹침, 화면 밖 배치, 의도하지 않은 줄바꿈을 허용하지 않습니다. 넘치는 내용을 단순히 숨기는 방식으로 해결하지 않습니다.

### 2) 고정 마스터 좌표

1920×1080px 캔버스의 왼쪽 위를 원점 (0, 0)으로 하며, 모든 단위는 px입니다. 일반 페이지에는 아래 마스터를 적용하고, 표지·목차·간지는 `2. 예외 페이지`에 명시한 좌표 예외를 따릅니다.

모든 X/Y는 Figma 속성 패널과 동일하게 박스의 좌측 상단 기준입니다. 푸터도 같은 기준을 사용하며, 글자 베이스라인이나 하단 정렬점과 혼용하지 않습니다.

| 요소 | 위치·정렬 기준 | 영역 크기 | 정렬 |
|---|---|---|---|
| 챕터명 | 좌측 상단 X=80, Y=164 | W=1760, H=32 | 좌측 |
| 제목 | 좌측 상단 X=80, Y=201 | W=1760, H=64 | 좌측 |
| 부제목 | 좌측 상단 X=80, Y=270 | W=1760, H=40 | 좌측 |
| 본문 | 좌측 상단 X=80, Y=360 | W=1760, H=584 | 외곽 영역 고정, 내부 그리드 사용 |
| 출처 | 좌측 상단 X=80, Y=984 | W=1560, H=28 | 좌측 |
| 저작권 표시 | 좌측 상단 X=80, Y=1012 | W=1560, H=28 | 좌측 |
| 페이지 번호 | 좌측 상단 X=1720, Y=1012 | W=120, H=28 | 우측 |

- 챕터명→제목, 제목→부제목의 박스 사이 간격은 5px입니다. 부제목 하단 Y=310부터 본문 시작 Y=360까지는 50px입니다. 텍스트 행간과 구분합니다. 이 50px는 제목 묶음 하단과 본문 사이의 세로 간격이며, 좌우 바깥 여백 80px나 카드 내부 패딩을 뜻하지 않습니다.
- 배경 분리는 공통 고정 마스터에 포함하지 않습니다. 제목 영역과 본문 영역을 배경으로 구분하는 경우에만 [본문-1 · 배경 분리형](../03-slide-types/README.md#본문-1--배경-분리형)을 적용합니다.
- 제목과 본문은 X=80~1840을 사용하여 좌우 바깥 여백을 각각 80px로 통일합니다. 푸터는 별도의 고정 기준점을 유지합니다.
- 챕터명이나 부제목이 없어도 예약 영역을 유지하고 나머지 요소를 위로 당기지 않습니다.
- 일반 마스터의 제목·부제목·챕터명은 각 한 줄 영역을 사용합니다. 명시적으로 선택한 전용 유형이나 최신 사용자 지시·직접 편집한 원본의 줄바꿈은 해당 장표의 예외로 보존합니다. 새 문구는 지정 영역에 맞게 다듬되, 기존 사용자 문구는 구조 수정만을 이유로 바꾸지 않습니다. 글자를 줄이거나 다음 영역을 밀지 않습니다.
- 본문은 Y=944를 넘지 않습니다. 본문 내용에 따라 헤더·푸터 위치를 이동하지 않습니다.
- 출처 박스는 Y=984~1012, 저작권·페이지 번호 박스는 Y=1012~1040입니다. 출처와 저작권 사이 여백은 0px이며 캔버스 하단까지 40px를 남깁니다.
- 저작권 표시와 페이지 번호에는 주석·출처 및 페이지 번호의 행간 28px를 적용합니다. 출처는 저자(연도)만 간결하게 표기하고, 상세 서지정보는 발표자 노트나 별도 원고에 보존하여 고정 영역을 넘지 않게 합니다.
- 페이지 번호 자릿수가 늘어나도 오른쪽 끝 X=1840는 유지합니다.
- 헤더 로고는 [공통 컴포넌트의 헤더 로고](components.md#헤더-로고)의 슬롯·크기·좌표 규칙을 따릅니다. 챕터명 등 고정 영역과 겹치지 않도록 확인합니다.

#### 일반 제목 묶음의 Auto Layout 구조

- 로고 헤더와 별개로 챕터명·제목·부제목을 하나의 세로 Auto Layout 부모로 구성합니다. 부모는 FRAME 또는 Auto Layout이 실제로 적용된 COMPONENT/INSTANCE이며 `layoutMode=VERTICAL`이어야 합니다. 겉모양만 맞춘 GROUP, `layoutMode=NONE` 프레임, 슬라이드에 텍스트를 직접 나열하는 방식은 대체물이 아닙니다.
- 같은 역할·장표 유형의 최신 라이브 원본을 먼저 읽고 실제 제목 묶음을 복제합니다. 색·폰트·좌표만 비슷하게 재작성하지 않습니다. 복제 후 대상 장표의 현재 문구와 스타일 범위를 보존하며, 원본의 문구나 사용자가 삭제·숨긴 요소를 되살리지 않습니다. 기존 인스턴스를 불필요하게 분리하지 않습니다.
- 관련 자식은 챕터명 → 제목 → 부제목 순서의 일반 흐름에 둡니다. 자식을 absolute positioning으로 빼서 좌표만 맞추지 않습니다. 공통 마스터는 좌측 정렬, 간격 5px, 패딩 0px입니다. 부모 시작점 (80, 164), 너비 1760px와 자식 높이 32/64/40px로 위 고정 좌표를 구현합니다.
- 부모·자식의 가로/세로 sizing과 텍스트 resize를 명시적으로 설정합니다. 공통 마스터의 부모 너비는 FIXED, 자식 너비는 FILL 또는 원본과 같은 고정 폭을 사용합니다. 높이는 원본의 FIXED 또는 HUG와 텍스트 고정 박스/자동 높이 방식을 함께 보존합니다. 모든 노드를 무조건 HUG로 바꾸지 않으며, 고정 높이도 정상 Auto Layout일 수 있습니다.
- 챕터명·부제목이 없는 공통 마스터는 빈 예약 슬롯 등 일반 흐름 안의 공간으로 기존 좌표를 유지하되 삭제한 텍스트를 복원하지 않습니다. 최신 사용자 원본이 빈 슬롯을 줄인 배치라면 그 예외를 유지합니다.
- 제목 부모는 정해진 안전 영역에 고정하고 본문·푸터와 분리합니다. 슬라이드 전체를 하나의 세로 흐름으로 바꿔 제목 길이가 본문·푸터를 밀게 하지 않습니다. 제목 묶음만 수정할 때 본문·푸터와 사용자 문구를 변경하지 않습니다.
- 최신 명시적 지시와 사용자가 직접 편집한 해당 역할의 원본 배치가 공통 마스터와 다르면 해당 장표의 예외로 먼저 기록·보존하고 실제 줄 수·경계·본문과의 비겹침을 검사합니다. 이전 좌표로 일괄 되돌리거나 정상 HUG/고정 높이 변형을 하나로 통일하지 않습니다. 표지·목차·간지도 각 전용 유형을 유지합니다.

### 3) 본문 그리드

| 구성 | 열 너비 | 열 사이 간격 | 전체 너비 |
|---|---|---|---|
| 1열 | 1760px | 없음 | 1760px |
| 2열 | 각 850px | 60px | 1760px |
| 3열 | 각 약 546.67px | 60px | 1760px |

- 모든 그리드는 본문 영역 (X=80, Y=360, W=1760, H=584) 안에서 사용합니다.
- 3열은 (1760 − 60 × 2) ÷ 3으로 계산합니다. 반올림으로 전체 너비를 초과하지 않도록 마지막 열에서 보정합니다.
- 열 수가 달라져도 본문 시작점과 외곽 여백은 바꾸지 않습니다.
- 서로 대응하는 항목과 같은 행의 카드는 시작점·높이·간격을 맞춥니다.
- 비교 표의 헤더 높이와 셀 패딩은 동일하게 유지합니다. 카드 내부 패딩은 컴포넌트 규칙을 따릅니다.

### 4) 컴포넌트

카드 등 공통 컴포넌트 규칙은 [공통 컴포넌트](components.md)를 함께 적용합니다.

### 5) 여백

- 콘텐츠 간 여백: 같은 역할의 간격을 페이지 간 동일하게 유지하며 상단 텍스트 5px·카드 내부 20px·카드 사이 60px를 구분합니다.
- 페이지 여백: 제목, 본문, 헤더, 푸터의 바깥 여백을 통일하고 항상 동일하게 합니다.


### 6) 위치

- 제목, 부제목, 챕터명, 본문, 헤더, 푸터는 모든 페이지에서 같은 위치에 있도록

### 7) 정렬

- 제목, 부제목, 챕터명은 항상 좌측 정렬
- Header, Footer와 콘텐츠 간 정렬은 맞추지 않습니다.

### 8) Header

- 좌측 상단: 작성자 브랜딩 로고.
- 우측 상단: 교육기관·대상 청중 로고. 사용하지 않기로 한 발표에서는 생략할 수 있습니다.
- 표지·뒤표지·목차·간지를 포함한 모든 장표에 같은 헤더 슬롯을 적용하며, 전용 샘플에 명시된 예외가 있으면 그 범위를 따릅니다.
- 로고의 위치·원본 비율·이번 강의의 지정 로고와 크기는 [헤더 로고 규칙](components.md#헤더-로고)을 따릅니다. 특정 교육기관 이름을 모든 발표의 고정 로고로 사용하지 않습니다.

### 9) Footer

푸터는 저작권 표시, 페이지 수, 출처 표기로 구성됩니다.

#### 저작권 표시

- 저작권 문구는 실제 권리자·연도·사용자 선택에 따라 입력합니다. 공개본의 자리표시자를 출력하지 않습니다.

#### 페이지 수

- 양식은 `0`으로 합니다.
- 표지와 같이 페이지를 표기하지 않는 페이지도 번호 산정에 포함합니다.
- 페이지 번호의 폰트 크기와 우측 기준점은 모든 내부 페이지에서 같습니다.

#### 출처 표기

- 저작권 표시 위에 여백 없이 작성합니다.
- 학생이 보는 장표의 출처는 `저자(연도)`만 표기합니다. 예: `Amershi et al. (2019)`. 저자가 조직이면 확인된 조직명을 사용합니다. 여러 자료는 세미콜론으로 구분합니다.
- 출처 앞의 `출처:` 접두어, 자료명·학술지·쪽수, 제작 방식 설명, 확인일 등은 장표 하단에 붙이지 않습니다.
- 장표 출처에는 URL 문자열과 클릭 가능한 하이퍼링크를 모두 넣지 않습니다. 기존 출처를 수정할 때 텍스트뿐 아니라 Figma 텍스트 범위의 hyperlink 속성도 제거합니다.
- 원출처의 전체 서지정보·URL·쪽수·자료 시점·인용 또는 재구성 여부·필요한 이용허락 정보는 발표자 노트나 별도 원고(예: Notion)에 보존하여 추적할 수 있게 합니다. 출처 표기를 줄인다고 사실관계나 이용허락 의무를 없애지 않습니다.
- 저자와 연도는 확인한 자료를 기준으로 합니다. 불명확한 저자·연도를 추정하여 만들지 않으며, 확인할 수 없는 연도는 `연도 미상`으로 표시합니다.
- 작성자 자신의 분석·제안에는 확인된 작성자명과 작성연도를 사용하고, 외부 자료를 자신의 저작물로 바꾸어 표시하지 않습니다.
- 실습으로 이동하는 링크, 제품 실행 링크, 활동용 QR 등은 출처 링크와 구분합니다. 이 규칙만으로 기능·실습 링크를 삭제하지 않습니다.
- 출처를 작게 줄이거나 잘라 숨기거나 페이지 번호 영역에 침범시키지 않습니다. 한 줄을 넘으면 출처 표기를 간결하게 정리하거나 장표를 분리합니다.

### 10) 폰트

- 제목, 부제목, 챕터명, 본문, 페이지수는 역할별 크기를 다르게 적용하고, 같은 역할은 모든 페이지에서 같은 크기를 유지합니다.
- 폰트 종류·굵기·크기·행간·색상은 [전체 디자인의 타이포그래피 표](../01-design-system/README.md#타이포그래피)를 따릅니다.

## 2. 예외 페이지

기본적으로 `1. 공통 레이아웃`의 고정 마스터와 본문 그리드를 적용합니다. 아래에 명시한 항목에만 예외를 적용하고, 나머지 공통 규칙은 유지합니다.

### 1) 표지 페이지

- 별도 표지 유형을 선택하면 [표지 전용 레이아웃](../03-slide-types/cover.md)을 따릅니다. 기본 텍스트 앞표지와 뒤표지는 아래 샘플 01 및 기본 텍스트 뒤표지 규칙을 적용합니다.
- AI 채용 과제·제안서는 제안서-표지-Front와 제안서-표지-Back을 기준으로 합니다.
- 일반 장표의 고정 좌표 대신 선택한 샘플의 표지 배치·간격·타이포그래피를 적용하고, 폰트는 Pretendard Variable로 유지합니다.
- 표지는 슬라이드 시작과 끝에 배치합니다. 부록이 있다면 끝 표지 뒤에 배치합니다.
- 페이지 번호를 표시하지 않습니다.
- 최종 프롬프트에는 cover.md의 실제 규칙과 샘플에서 확인한 제작 값을 함께 포함합니다.

#### 기본 텍스트 표지 · 샘플 01

구성 기준: 아래 일반 텍스트 표지 프리셋. 별도 표지 유형을 지정하면 cover.md의 해당 규칙과 사용자 제공 레퍼런스를 적용합니다.

- 캔버스 1920×1080px, 전체 배경 #F2F5FA를 사용합니다. 본문-1 유형의 배경 분리는 적용하지 않습니다.
- 상단 영문 캡션은 넣지 않습니다. 제목 → 부제목 → 작성자·날짜 순서로 좌측 정렬합니다.
- 콘텐츠 묶음은 X=80, Y=388, W=1440입니다. 세로 자동 레이아웃, 요소 간격 24px, 내부 패딩 0px를 사용합니다.
- 아래 Y값은 제목 두 줄 기준입니다. 제목 줄 수가 달라지면 묶음 시작점과 24px 간격을 유지하고 뒤 요소는 자동으로 흐르게 합니다.
- 모든 폰트는 Pretendard Variable입니다. 이 표의 크기·행간은 기본 텍스트 표지 전용 값입니다.

| 요소 | 좌측 상단 X/Y | 너비·높이 | 굵기 | 크기 / 행간 | 색상 |
|---|---|---|---|---|---|
| 제목 | 80 / 388 | 1440 / 192 (두 줄) | Bold 700 | 80 / 96px | Grey 900, 핵심 구절만 Blue 500 |
| 부제목 | 80 / 604 | 1440 / 40 | Medium 500 | 40 / 40px | Grey 600 |
| 작성자·날짜 | 80 / 668 | 1440 / 32 | Medium 500 | 24 / 32px | Grey 600 |
| 저작권 | 80 / 1012 | 1560 / 28 | Regular 400 | 20 / 28px | Grey 600 |

- 부제목은 발표 주제를 짧게 표현하고 한 줄을 유지합니다. 샘플의 기존 디자인 검토용 설명은 포함하지 않습니다.
- 작성자·날짜의 형식 예시는 `[작성자] | YYYY.MM`입니다. 실제 작성자·날짜·시간대는 사용자가 지정합니다. 미입력 값은 만들지 않습니다.
- 저작권은 공통 문구를 유지하고 페이지 번호는 표시하지 않습니다.
- 제목 최대 두 줄, 부제목 한 줄에 맞게 문장을 정리합니다. 글자를 임의로 축소하지 않습니다.

#### 기본 텍스트 뒤표지

- 기본 텍스트 앞표지를 사용한 발표 자료는 뒤표지에도 위 샘플 01의 배경·배치·폰트·색상·간격을 동일하게 적용합니다.
- 제목은 `감사합니다.` 등 짧은 마무리 문구를 기본으로 하되, 사용자가 지정하거나 직접 수정한 뒤표지 문구가 있으면 유지합니다. 제목은 80/96px, Bold 700, Grey 900을 유지하며 의미상 강조가 필요한 핵심 구절에만 Blue 500을 사용합니다.
- 부제목에는 발표의 핵심 제안을 한 줄로 요약합니다. 앞표지와 동일한 40/40px, Medium 500, Grey 600을 사용합니다.
- 작성자·날짜는 앞표지에서 확정한 값과 형식을 사용하며, 24/32px, Medium 500, Grey 600을 유지합니다. 사용자 지정 행사일·표기 형식도 그대로 따릅니다.
- 콘텐츠 묶음은 X=80, Y=388, W=1440, 세로 자동 레이아웃, 간격 24px, 내부 패딩 0px입니다. 제목이 한 줄이면 제목 Y=388/H=96, 부제목 Y=508/H=40, 작성자·날짜 Y=572/H=32가 됩니다. 제목이 두 줄이면 위 앞표지 표의 좌표를 그대로 사용합니다.
- 저작권은 X=80, Y=1012, W=1560, H=28에 공통 문구를 표시하고, 20/28px, Regular 400, Grey 600을 사용합니다.
- 상단 영문 캡션과 페이지 번호는 표시하지 않습니다. 뒤표지도 전체 페이지 수 산정에는 포함합니다.
- 제안서·자기소개 등 전용 표지 유형을 선택한 경우에는 이 기본 뒤표지 대신 `cover.md`의 해당 Back 샘플을 적용합니다.

### 2) 목차

- 목차 페이지는 [목차 전용 레이아웃](../03-slide-types/contents.md)의 선택한 유형을 따릅니다. 현재 기준은 목차-1입니다.
- 일반 장표의 제목·부제목·본문 좌표 대신 목차 전용 배치·여백·타이포그래피를 적용합니다.
- 폰트는 Pretendard Variable을 유지하고 명시하지 않은 항목은 공통 규칙을 따릅니다.
- 목차 자체의 페이지 번호는 표시하지 않습니다. 항목별 페이지 범위는 실제 슬라이드 순서에 맞춰 표시합니다.
- 최종 프롬프트에는 contents.md의 실제 규칙도 함께 포함합니다.

### 3) 간지
- 목차의 큰 주제마다 본문 앞에 반드시 배치합니다. 기존 간지는 재사용하며 [챕터 간지 규칙](../03-slide-types/chapter-divider.md)을 함께 적용합니다.
- 페이지 번호는 표시하지 않지만 전체 페이지 산정에는 포함합니다.
- 간지는 내부 페이지의 제목·본문 고정 좌표를 적용하지 않아도 됩니다. 다만 좌우 최소 80px 안전 여백과 1920×1080px 캔버스를 지킵니다.
