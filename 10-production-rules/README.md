# 제작·수정·검수·출력

제작 조건은 이 문서에서 관리합니다. [캔버스 장표 배치](canvas-layout.md)와 [검수.md](검수.md)를 함께 읽고 적용합니다. 아래 빈칸은 미정 상태로 유지합니다.

## 입력 양식

- 진행 방식: [입력]
- 확인 시점: [입력]
- 속도·완성도 우선순위: [입력]
- 결과물 형식·편집 가능 요소: [입력]
- 검수 범위: [입력]
- 수정 대상·변경 허용·유지할 요소: [입력]
- 대표 장표 수·발표자 노트·파일 이름: [입력]

## 입력 항목 사용법

- 진행 방식·확인 시점·속도와 완성도 우선순위·결과물 형식과 편집 가능 요소는 제작에 필요한 필수 항목입니다. 이미 확정한 값과 단계는 다시 묻지 않습니다.
- 검수 범위는 [검수.md](검수.md)를 기본으로 적용합니다. 위 입력란에는 추가하거나 제외할 범위가 있을 때 기록합니다.
- 수정 대상·변경 허용·유지할 요소는 기존 결과물을 수정할 때 확인합니다.
- 대표 장표 수·발표자 노트·파일 이름은 선택 항목입니다.
- 필요한 미정 값만 질문하고 답변은 이 문서 또는 이번 발표의 입력 기록에 남깁니다. 예시를 확정값으로 사용하지 않습니다.

## 캔버스 장표 배치

Figma 페이지 위에서 장표를 챕터별로 묶고 행·열 순서에 맞춰 추가·이동하는 규칙은 [canvas-layout.md](canvas-layout.md)를 따릅니다. 작업 전에 현재 사용자 배치와 그룹 경계를 확인하며, 한 장 내부의 좌표를 다루는 02-common-layout과 구분합니다.

## 검수

검수의 상세 기준은 [검수.md](검수.md)를 따릅니다. 최종 프롬프트를 조립할 때는 이 문서의 제작 조건과 canvas-layout.md·검수.md의 실제 규칙을 모두 [제작·수정·검수] 구역에 포함합니다. 링크만 전달하지 않습니다.

## 작성 원칙

직접 선택한 진행 방식과 이미 완료한 확인 단계를 존중합니다. 출력 형식의 지원 여부는 실제 제작 도구에서 확인합니다. 공유 대상과 권한은 실제 공유 요청이 있을 때 정합니다.

## 사용자가 완성한 장표를 수정할 때

- 작업 직전 라이브 장표의 보이는 문구·삭제·순서·구성을 기준으로 삼습니다. 사용자가 삭제한 장표·부제목·출처 문구를 과거 스냅샷을 근거로 되살리지 않습니다.
- 번호는 바뀔 수 있으므로 사용자가 지칭한 장표를 제목·내용·노드 ID로 확인합니다. 최신 번호와 과거 번호의 대응을 유지합니다.
- hidden archive 안의 예전 구성은 현재 장표로 해석하지 않습니다. 텍스트를 추출할 때 해당 노드뿐 아니라 조상 컨테이너의 visible 상태도 확인합니다.
- '내가 수정했다'는 명시적 피드백은 그 결과를 읽고 인접 사례·양식에 반영하라는 신호입니다. 수정된 원본을 이전 AI안으로 교체하지 않습니다.
- AI 작성본과 사용자 완성본을 비교할 때, 직접 비교 가능한 변경·사용자의 명시 지시·원인 미확인 차이를 나누어 기록합니다. 스냅샷 차이만으로 모두 사용자의 수정 또는 AI의 오류라고 단정하지 않습니다.
- 순서·번호 정리 요청은 그 범위만 수정합니다. 현재 남은 장표를 기준으로 캔버스 위치·푸터·레이어명·목차 범위를 함께 검수하고, 본문 내용이나 숨김 상태를 추가로 바꾸지 않습니다.

- 사용자가 한 카드를 직접 고치고 '다른 카드도 이렇게'라고 하면, 그 카드를 기준으로 대응되는 형제 카드만 맞춥니다. 기준 카드의 삭제 문구·줄바꿈·그룹 구조를 다시 바꾸지 않습니다. 수정 후 기준 카드가 그대로인지 함께 확인합니다.
