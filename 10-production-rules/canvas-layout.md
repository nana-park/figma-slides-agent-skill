# Figma 캔버스의 장표 배치

## 적용 범위

Figma 페이지 위에 여러 장표 프레임을 배치하거나 기존 장표를 추가·이동할 때 적용합니다. 한 장 내부의 제목·본문·푸터 좌표는 02-common-layout, 이야기 순서는 08-storytelling, 장표별 내용은 09-slide-content를 따릅니다. 이 문서는 장표 사이의 공간 순서와 묶음을 다룹니다.

## 먼저 현재 배치를 읽기

- 제작·수정 전에 대상 파일과 페이지를 확인하고 현재 장표의 노드 ID, 이름·번호, 유형, 부모, 크기와 위치를 읽습니다. 이전 작업의 좌표나 오래된 스냅샷만으로 배치하지 않습니다.
- 표지·도입·목차, 챕터 간지, 본문, 하위 주제 시작, 회고·마무리, 부록의 경계를 확인합니다. 사용자가 만든 행·열과 의도적으로 비워 둔 칸도 구성의 일부로 취급합니다.
- 기존 장표의 공통 열 시작점·행 시작점·가로세로 간격을 확인해 같은 규칙을 사용합니다. 특정 발표에서 관측한 열 수나 절대 X/Y를 모든 발표의 고정값으로 만들지 않습니다.
- 행·열 패턴이 명확하면 재질문하지 않고 따릅니다. 빈칸이 의도된 경계인지, 어느 챕터에 속하는지 불명확하고 결과에 영향을 주는 경우에만 해당 부분을 확인합니다. 새 파일에 기준 배치가 없다면 이번 제작 조건에서 배치를 정합니다.
- 장표 프레임의 캔버스상 위치와 프레임 내부 콘텐츠의 좌표를 구분합니다. 서로 다른 부모의 X/Y는 그대로 비교하지 않고 페이지 기준 위치로 확인합니다.

## 챕터와 읽기 순서

- 목차의 큰 주제(대분류)가 시작되는 곳에는 해당 본문 앞에 간지를 반드시 둡니다. 첫 챕터도 포함하며, 이미 사용자가 만든 간지가 있으면 재사용합니다. 세부 유형 규칙은 03-slide-types/chapter-divider.md를 따릅니다.
- 사용자가 정한 챕터 묶음과 읽기 방향을 우선합니다. 왼쪽에서 오른쪽, 위에서 아래로 이어지는 행렬이면 해당 순서대로 장표가 읽히도록 유지합니다.
- 챕터 간지가 새 행의 첫 열에서 시작하는 배치라면 그 경계를 유지합니다. 해당 챕터 본문은 간지 오른쪽부터 이어지고, 행이 차면 같은 묶음의 다음 행으로 넘어갑니다.
- 다음 챕터 간지를 앞 챕터의 남은 칸에 끼워 넣지 않습니다. 하위 주제·사례가 새 행에서 시작하도록 구분된 곳도 유지합니다.
- 표지·도입·목차, 회고·마무리, 부록이 별도 행이나 영역으로 구분되어 있으면 그 경계를 보존합니다. 모든 빈칸을 채우는 일괄 정렬로 사용자의 구분을 없애지 않습니다.
- 캔버스의 공간 순서가 확정된 원고·발표 순서를 표현해야 합니다. 생성 시간이나 기존 프레임 이름의 마지막 번호를 발표 순서로 간주하지 않습니다.

## 장표 추가와 이동

- 새 장표는 내용상 소속된 챕터와 앞뒤 장표를 먼저 정하고 그 위치에 넣습니다. 관련 연구·근거 장표도 설명하는 본문 바로 뒤 등 확정된 위치에 포함합니다.
- 나중에 만들었다는 이유로 덱 맨 끝이나 멀리 떨어진 임시 영역에 두지 않습니다. 본문에 넣기로 한 장표를 캔버스 바깥의 부록처럼 남겨 두지 않습니다.
- 삽입으로 공간이 부족해지면 현재 열 수·간격·챕터 경계를 유지하면서 필요한 장표와 뒤쪽 묶음만 이동합니다. 다른 챕터에 끼워 넣거나 장표를 겹쳐 놓지 않습니다.
- 이동은 기존 장표를 대상으로 합니다. 위치를 바꾸기 위해 장표를 삭제·재생성하거나 중복 복사하지 않습니다. 노드 ID, 사용자가 편집한 문구·도형·스타일·간지 구성은 유지합니다.
- 실행 직전에 최신 상태를 다시 확인합니다. 다른 작업자나 사용자가 수정한 경우 현재 상태에 맞춰 대상과 이동 범위를 조정하고, 영향을 받지 않는 편집은 보존합니다.

## 번호와 원고 연결

- 승인된 추가·이동으로 발표 순서가 바뀌면 원고의 발표 순서, 프레임의 표시용 순번, 표시되는 페이지 번호, 목차의 페이지 범위를 함께 대조해 맞춥니다.
- 기존 원고 식별자와 새 발표 순번이 다르면 둘의 대응을 유지합니다. 이전 번호로 언급된 장표도 제목과 노드 ID로 추적할 수 있어야 합니다.
- 표지·목차·간지의 페이지 번호 표시 여부와 전체 페이지 산정 방식은 02-common-layout의 확정 규칙을 따릅니다. 번호가 보이지 않는 장표를 발표 순서에서 누락하지 않습니다.
- 순서 조정만 요청받았다면 본문 내용·디자인을 함께 다시 작성하지 않습니다.

- 번호를 맞추기 직전에 라이브 캔버스의 대상 장표를 다시 읽고, 사용자가 새로 만든 장표까지 포함한 최신 읽기 순서를 확정합니다. 과거 장수나 이전 마지막 번호로 대상 범위를 고정하지 않습니다.
- 각 장표의 노드 ID, 최신 읽기 순번, 화면에 보이는 실제 제목, 페이지 번호 표시 여부를 대조한 뒤 푸터 번호와 최상위 장표 프레임의 레이어 이름을 함께 맞춥니다. 레이어 이름의 제목은 기존 이름이나 원고의 오래된 제목 대신 현재 장표의 실제 제목을 사용하며, 제목 안의 줄바꿈은 공백으로 정리합니다.
- 레이어 이름은 예를 들어 `NN · 실제 제목`으로 구성합니다. 순번은 최신 읽기 순서와 표시되는 푸터 번호에 대응하며, 특정 발표의 접두어나 마지막 번호를 다른 발표에 강제하지 않습니다.
- 수정 후 라이브 상태를 다시 읽어 사용자 추가 장표의 포함 여부, 순번의 중복·누락, 실제 제목과 레이어 이름의 불일치, 푸터와 레이어 순번의 불일치가 없는지 확인합니다. 번호를 숨기는 표지·목차·간지도 순번에는 포함하되 숨김 규칙을 유지합니다.

## 예외와 작업용 자료

- 사용자가 별도로 지정한 부록, 그래프 테스트, 참고자료, 발표자 노트, 작업용 요소는 본문 장표와 구분합니다. 기존 구분과 용도를 보존하고 발표 순서에 섞지 않습니다.
- 그래프가 있다는 이유만으로 실제 발표 장표를 별도 작업 영역으로 빼지 않습니다. 작업용 자료라는 근거가 없으면 임의로 제외하지 않습니다.
- 임시 위치에서 만든 장표는 완료 전에 확정된 본문 위치로 옮깁니다. 남아야 하는 예외 자료가 있으면 범위와 이유를 결과에 알립니다.

## 프롬프트와 검수에 포함하기

최종 프롬프트의 [제작·수정·검수]에 위 규칙의 실제 내용을 포함합니다. 이번 발표에서 확인한 행·열·간격·그룹 경계·예외는 이번 발표의 입력 기록에 남기며, 다른 발표에 적용할 영구 좌표로 바꾸지 않습니다. 제작 후에는 [검수 규칙](검수.md)의 캔버스 배치 항목을 확인합니다.
