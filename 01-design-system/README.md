# 전체 디자인

## 기본 설정 · 입력 양식

- 화면 비율/크기: 1920x1080
- 배경색 HEX: #F2F5FA
- 본문색 HEX: #191F28 (Grey 900)
- 강조색 HEX: #3182F6 (Blue 500)
- Sub text HEX: #6B7684 (Grey 600)
- 보조색 HEX: [입력]
- 폰트: Pretendard Variable
- 제목/본문/주석 글자 크기: 아래 타이포그래피 표 기준
- 분위기: [입력]
- 아이콘/사진/일러스트 스타일: [입력]
- 피하고 싶은 표현: [입력]

## 타이포그래피

- 1920x1080 Figma 화면 기준이며 폰트 크기와 행간의 단위는 px입니다.
- 행간은 줄 높이(line-height)를 뜻합니다.
- 한글, 영문, 숫자, 표, 차트 라벨, 캡션, 출처, 페이지 번호 등 제작하는 모든 텍스트에 Pretendard Variable만 사용합니다.
- 다른 폰트로 대체하거나 폴백으로 출력하지 않습니다. 폰트가 준비되지 않았으면 설치·임베딩을 해결한 뒤 출력합니다.
- 추가로 입력한 디자인 및 컴포넌트 예시에 포함된 글자는 원본의 일부로 취급합니다. 새로 덧붙이는 설명·라벨에는 반드시 지정 폰트를 사용합니다.
- 역할별로 굵기(weight)와 크기를 다르게 적용합니다. 
- 아래 수치는 이 스킬의 기본 제작값입니다.

|---|---|---|---|---|---|
| 시작·끝 표지의 메인 제목 | Pretendard Variable | Bold 700 | 80px | 96px | Grey 900 · #191F28 |

### 적용 규칙

- 기본 프리셋은 제목 48/64, 부제목 28/40, 챕터명 24/32, 카드 소제목 30/48, 큰 본문 30/40px입니다.
- 카드 버튼 라벨은 Pretendard Variable Bold 700, 20px / 행간 20px를 사용합니다. 상세 색상과 형태는 02-common-layout/components.md를 따릅니다.

- 기존 사용 위치·역할·정렬과 배치 좌표는 유지하며, 위치 규칙은 02-common-layout을 따릅니다.
- 본문 영역 안에서 큰 본문은 핵심 요약, 기본 본문은 일반 설명, 작은 본문은 보충 내용에 사용합니다. 기본값은 25px / 행간 30px입니다.
- 작은 본문도 Grey 900을 유지하며, 보조 설명(Sub text)에만 Grey 600을 적용합니다.
- 샘플 01·03에서 확정한 크기를 기준으로 나머지 기본 위계를 맞춥니다. 이미 조정한 샘플의 텍스트와 본문 계열을 다시 일괄 축소하지 않습니다.
- 간지·목차의 기본 제목은 일반 장표 제목과 같은 48/64px로 조정합니다. 핵심 수치·KPI는 기존 64/80px에서 75%로 축소한 48/60px를 사용합니다.
- 표·그래프 라벨은 기본 본문 25px의 80%인 20px로 조정하고, 작은 본문과 같은 행간 25px를 사용합니다. 축·눈금·범례·수치 라벨에 동일하게 적용합니다.
- 본문·도표 주석은 보조 설명과 같은 20/25px를 사용합니다. 출처와 페이지 번호는 축소 대상에서 제외하며 크기 20px·행간 28px와 기존 색상·좌표를 유지합니다.
- 기본 텍스트 앞·뒤표지의 세부 값은 02-common-layout을 따릅니다. 03-slide-types에서 지정한 전용 표지·목차 샘플의 명시적 예외는 해당 샘플 규칙을 우선합니다.
- 제목 전체를 강조색으로 바꾸지 않고, 메시지의 핵심 단어 또는 짧은 구절에만 Blue 500을 적용합니다. 기본 제목은 Grey 900을 유지합니다.
- 제목 안 강조 단어는 주변 제목과 같은 크기·행간·굵기를 유지하고 색상으로 구분합니다.
- 같은 역할은 모든 장표에서 같은 폰트·굵기·크기·행간·색상 규칙을 유지합니다.
- 글이 넘치면 폰트 크기를 임의로 줄이지 않고 내용을 정리하거나 장표를 분리합니다.
- 시작·끝·목차·간지의 페이지 번호 표시 여부는 '02-common-layout'규칙을 따릅니다.
- PPTX 등 단위가 다른 출력은 장표 크기에 맞춰 비례 변환합니다. 위 px 숫자를 그대로 pt로 사용하지 않습니다.
- “같은 폰트 크기”는 제목·부제목·챕터명·페이지 번호를 모두 같은 크기로 만들라는 뜻이 아니라, 각 역할의 크기를 모든 내부 페이지에서 동일하게 유지한다는 의미로 적용합니다.
- 자간은 0으로 통일한다. 공간을 맞추기 위한 임의의 장평·자간 압축을 하지 않는다.
- 본문과 보조 라벨도 역할별 토큰을 일관되게 사용한다. 과밀한 페이지의 본문을 보조 라벨 스타일로 바꾸어 우회하지 않는다.
- 텍스트 자동 맞춤, 페이지별 글자 축소, 폰트 혼용을 금지한다.
- 굵기의 대비와 명도 차이로 위계를 만든다. 한국어 가독성을 위해 원본의 지나치게 타이트한 제목 행간은 위 값으로 교체한다.

## Blue 계열의 강조 위계

1차 강조색은 Blue 500으로 유지합니다. 
도형·그래프·국소 강조 영역의 강조 강도를 조절할 때는 임의의 색이나 투명도 대신 아래 단계를 사용합니다. 텍스트 색상은 타이포그래피 표를 우선합니다.

| 단계 | HEX | 장표에서의 활용 |
|---|---|---|
| Blue 50 | #E8F3FF | 가장 약한 강조 영역의 채움 |
| Blue 100 | #C9E2FF | 옅은 강조 영역·보조 요소의 채움 |
| Blue 200 | #90C2FF | 약한 보조 도형·그래프 항목 |
| Blue 300 | #64A8FF | 중간 강도의 보조 강조 |
| Blue 400 | #4593FC | 1차 강조보다 한 단계 약한 강조 |
| Blue 500 | #3182F6 | 1차 강조: 핵심 수치·키워드·주요 그래프 |
| Blue 600 | #2272EB | 도형·선·그래프의 진한 강조 |
| Blue 700 | #1B64DA | 밝은 채움 위 도형·선·그래프의 진한 강조 |
| Blue 800 | #1957C2 | 더 높은 대비가 필요한 도형·선·그래프 |
| Blue 900 | #194AA6 | 도형·선·그래프의 가장 짙은 Blue 강조 |

### 적용 규칙

- 텍스트 색상은 타이포그래피 표를 우선합니다.
- 제목의 핵심 단어·챕터명·핵심 수치는 Blue 500을 유지합니다.
- 본문·보조 설명·출처·페이지 번호는 타이포그래피 표의 Grey 계열을 유지합니다.
- Blue 50~400은 도형·그래프·국소 강조 영역의 강도를 조절할 때 사용합니다.
- Blue 600~900은 도형·선·그래프에 더 높은 대비가 필요할 때 사용합니다.
- 텍스트 색상을 대비 문제로 변경해야 한다면 임의로 바꾸지 않고 확인합니다.
- 같은 역할에는 모든 장표에서 같은 색상 단계를 적용합니다. 모든 단계를 한 장에 사용할 필요는 없습니다.
- 페이지 전체 배경색은 기본 설정을 따르며, Blue 영역 채움과 구분합니다.

## 입력 안내

- 필수: 화면 비율 (사용자 확정값).
- 필수: 디자인 성격·분위기 (보고서형/시각 중심 등. 선택지는 예시).
- 필수: 컬러 조합 (README의 용도별 기본 조합).
- 선택: 배경색 (현재 입력값 유지).
- 필수: 폰트 (사용자 확정값).
- 필수: 브랜드 필수 규칙 유무 (없음 가능).
- 조건부: 브랜드 파일·필수 색상·폰트·로고 규칙 (브랜드 사용 시).
- 선택: 정보 밀도·이미지 비중·금지 표현.
- 선택: 텍스트 크기·보조색.

이미 기록된 값은 다시 묻지 않습니다. 필요한 값이 없으면 질문하고 이 문서에 반영합니다. 선택 항목은 비워도 되며, 작성 예시는 확정값이 아닙니다.
