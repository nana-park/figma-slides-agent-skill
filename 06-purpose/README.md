# 발표 목적

발표마다 작성합니다. 누구에게 무엇을 전달하고 어떤 행동을 이끌어낼지 정합니다.

## 입력 양식

- 발표 주제: [입력]
- 청중: [입력]
- 발표 목적: [입력]
- 청중이 기억할 한 문장: [입력]
- 발표 후 요청할 행동/결정: [입력]
- 발표 시간: [입력]
- 장표 수: [입력]
- 사용 언어: [입력]

## 작성 예시

경영진에게 신규 서비스 파일럿 승인을 요청하는 10분 발표, 8장.

[전체 작성 안내로 돌아가기](../README.md)

## 입력 안내

- 필수: 발표 주제.
- 필수: 청중과 발표 목적.
- 필수: 핵심 메시지와 원하는 행동.
- 필수: 발표 시간·장수 및 장수 고정 여부 (장수 제안 위임 가능).
- 선택: 청중의 사전 지식·관심사·예상 반론.
- 선택: 사용 언어.

이미 기록된 값은 다시 묻지 않습니다. 필요한 값이 없으면 질문하고 이 문서에 반영합니다. 선택 항목은 비워도 되며, 작성 예시는 확정값이 아닙니다.
